# Owned Expansions Settings (Owned Sets)

To simplify the interface and tailor the application to your actual Dominion card collection, you can configure the display to show only the expansions you physically own.

---
## 1. Enabling the Configuration

- **Activation Option**: Toggle the "Use Custom Configuration for Set Display" switch in the settings.
- **Set Selection**: Individually check each expansion box present in your collection. You can use the "Select All" button to quickly check all expansions.
- **Sort Options**: Sort the list of expansions **Alphabetically** or by release **Date** to locate your boxes more easily.
- **Edition Management**: For sets with multiple versions (e.g., Intrigue 1st and 2nd edition), you can enable or disable each edition separately.

---
## 2. Impact on the Main Page (Random Generation)

Excluding an expansion changes the behavior of the home page as follows:
- **Simplified Filters**: Only the expansions selected as owned will appear in the list of selectable sets for deck generation.
- **Automatic Deselection**: If an excluded expansion was previously selected for generation, it will be automatically deselected.
- **Current Deck Invalidation**: If the currently displayed deck contains cards from excluded expansions, those cards will be considered invalid.

---
## 3. Impact on Predefined Games

- **Hidden Filters**: In the predefined games section, unselected expansions will no longer appear in the filter lists.
- **Scenario Filtering**: When browsing recommended setups for an owned expansion, all game scenarios that require at least one card from an excluded expansion are automatically hidden. This ensures you only see configurations playable with your physical cards.

---
## 4. Impact on Game Rules

- **Clean Rules Mosaic**: Only rules for expansions checked as owned are displayed in the application's rules mosaic.

---
## 5. Impact on Box Contents

- **Targeted Visualization**: Only expansions set as owned remain visible in the box content presentation list.
- **Automatic Adjustment**: If the box currently being viewed is excluded from your collection, the application automatically switches to the first remaining owned box in the list.
